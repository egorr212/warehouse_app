# 📦 WMS Контроль ПВЗ

Программа для автоматизации работы пунктов выдачи заказов (ПВЗ). 
Помогает вести учет посылок на складе и выдавать их клиентам.

Проект написан на **Python** с использованием графической библиотеки **Tkinter** и базы данных **SQLite**. Работает полностью локально и автономно.

## 🔥 Главные фишки
* **🔎 Умный подбор полок:** Программа автоматически находит в базе данных только свободные ячейки нужного размера, исключая человеческие ошибки.
* **📊 График загрузки:** В реальном времени рассчитывает процент заполненности склада и выводит аналитику на цветную полосу (`Progressbar`).
* **💻 Стильный интерфейс:** Приложение оформлено в современной темной теме (`Premium Dark Mode`).

## 🚀 Как запустить проект
1. Скачайте файлы `main.py` и `styles.py` в одну папку.
2. Запустите файл `main.py` командой:
   ```bash
   python main.py
   ```
